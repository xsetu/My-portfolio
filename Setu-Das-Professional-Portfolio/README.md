# Setu Das — Portfolio

## Run locally
Open `index.html` in a browser.

## Add your resume
Place your final PDF in this folder as:
`Setu-Das-Resume.pdf`

The portfolio already links to that filename.

## Deploy
This is a static site and can be deployed to GitHub Pages, Netlify, Vercel, or any static hosting provider.

## Important
The project descriptions and credentials are based on the supplied resume. Replace/add GitHub repository links, live demos, screenshots, measurable results, and technical write-ups when those details are available.
